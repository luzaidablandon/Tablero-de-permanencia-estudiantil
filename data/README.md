# Datos

`data.csv`: conjunto **Predict Students' Dropout and Academic Success** (UCI Machine Learning Repository, id 697),
4.424 estudiantes × 37 variables, sin valores nulos.

- Fuente: https://archive.ics.uci.edu/dataset/697
- Cita: Realinho, V., Machado, J., Baptista, L., & Martins, M. V. (2022). Predicting student dropout and academic success. *Data*, 7(11), 146. https://doi.org/10.3390/data7110146
- Licencia de los datos: CC BY 4.0 (atribución obligatoria).

Los datos son anonimizados y provienen de una institución de educación superior portuguesa; el dashboard es un ejercicio académico y no debe usarse para decidir sobre estudiantes reales.
